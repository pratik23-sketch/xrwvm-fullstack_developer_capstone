# Cars Dealership Application

## Project Description
The Cars Dealership Application is a full-stack web application developed using Django and React. It allows users to explore car dealerships, view dealership information, read customer reviews, and submit their own reviews.

## Technologies Used
- Python
- Django
- JavaScript
- React
- HTML
- CSS
- REST APIs

## Main Features
- User registration and login
- View all car dealerships
- Search dealerships by state
- View dealership details
- Read customer reviews
- Submit dealership reviews
- Car makes and models information
- Admin dashboard

## Project Structure
- `server/djangoapp` – Django application and backend functionality
- `server/djangoproj` – Django project configuration
- `server/frontend` – Frontend application
- `server/database` – Database-related files

## Installation and Setup
1. Clone the repository.
2. Navigate to the server directory.
3. Install dependencies:

   `python3 -m pip install -r requirements.txt`

4. Apply database migrations:

   `python3 manage.py migrate`

5. Start the Django server:

   `python3 manage.py runserver 0.0.0.0:8000`
